# 광고 방패 — 가족용 광고·사기 차단 앱

---

## 🔴 새 버전 직접 설치하기

👉 **[새버전_설치방법.md](새버전_설치방법.md)**

- 앱은 **스스로 업데이트하지 않습니다** (버전 1.3 부터). 새 버전은 오너가 직접 설치합니다.
- 부모님 폰 확인: 광고 방패 화면 **맨 위, 제목 바로 밑** 의 `버전 1.몇`

---

## 토토 의심 주소 막기 켜기 / 끄기

👉 **[`collector/차단스위치.txt`](collector/차단스위치.txt)** 파일을 열고 → 연필 아이콘 → 분류마다 `끄기` 또는 `켜기` 로 바꿔 → **Commit changes**

- 처음에는 전부 `끄기` (관찰만). 무엇을 켤지 고르는 법·관찰 결과 → [collector/README.md](collector/README.md)
- 부모님 폰 반영: 하루 한 번, 와이파이에서 (와이파이에서 앱의 **지금 새로고침** 을 누르면 바로)
- 앱 **버전 1.2 부터** 효과 (1.1 에는 이 기능이 없음 — 광고 방패 화면 맨 위 버전 숫자로 확인)
