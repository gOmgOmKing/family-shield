## 🔴 자동 업데이트 켜기 / 끄기

👉 **[`lists/AUTO_UPDATE.txt`](lists/AUTO_UPDATE.txt)** 파일을 열고 → 연필 아이콘 → **맨 아래 한 줄**을 `끄기` 또는 `켜기` 로 바꿔 → **Commit changes**

- `끄기` : 부모님 폰은 새 버전을 스스로 받지 않음. 새 버전은 오너가 직접 설치 → [새버전_설치방법.md](새버전_설치방법.md)
- `켜기` : 부모님 폰이 하루 한 번 이 저장소의 최신 릴리스에서 새 버전을 받아 설치 창을 띄움
- 지금 어느 쪽인지는 그 파일 맨 아래 줄이 정답 (이 페이지에는 적지 않음)
- 부모님 폰 반영: 최대 6시간 (부모님이 앱에서 **지금 새로고침** 을 누르면 바로)
- 부모님 폰 확인: 광고 방패 화면 **맨 위, 버전 바로 밑** 에 `자동 업데이트: 꺼짐 / 켜짐`
