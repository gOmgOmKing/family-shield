## 막기로 하면 — 차단 스위치 (만들어 둠, 지금은 전부 끄기)

- **켜고 끄기는 AI 없이 됩니다.** GitHub 에서 [`collector/차단스위치.txt`](차단스위치.txt) 를 열고,
  연필(✏️ Edit) → 분류 줄의 `끄기` 를 `켜기` 로 바꾸기 → **Commit changes** 순서로 하면 됩니다.
  `lists/AUTO_UPDATE.txt` 와 같은 방식이고, 몇 분 안에 GitHub 이 차단 파일을 다시 만듭니다.
- **아직 부모님 폰은 이 파일을 받지 않습니다.** 앱이 이 파일을 받는 기능은 개발 세션이 다음 새 버전에 넣습니다.
  그 새 버전을 부모님 폰 두 대에 설치한 뒤부터 스위치가 실제로 막습니다.
- 허용 목록(`lists/allow.txt`)이 늘 우선이고, 동행복권 같은 합법 공식 사이트는 켜도 들어가지 않습니다.

## 켜기·끄기·직접 돌리기 (관찰 자체)

GitHub 저장소 → **Actions** → 왼쪽 **토토 후보 관찰**에서 합니다.
- 직접 한 번 돌리기: **Run workflow**
- 관찰 멈추기: 오른쪽 위 **…** → **Disable workflow**
- 다시 켜기: 같은 자리의 **Enable workflow**

실패하면 그날 실행이 빨간불로 끝나고, 이유는 결과 폴더의 `daily.tsv` 에 적힙니다.
60일 동안 저장소에 아무 변화가 없으면 GitHub 이 매일 실행을 저절로 끕니다. 그때는 **Enable workflow** 를 누릅니다.
