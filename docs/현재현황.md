- 블로그 **전면(비네트) 광고**: 시험한 티스토리에서 보호 없이도 전면 광고가 뜨지 않아 직접 비교 못 함. 전면 광고는 막힌 `googlesyndication.com`·`doubleclick.net` 에서 오므로 같이 막혀야 정상이지만 눈으로 확인 못 함.
- **"아무 데나 누르면 쿠팡" / 뒤로 가기 가로채기**: 재현되는 페이지를 찾지 못함. 쿠팡 위젯 서버(`ads-partners.coupang.com`)는 막히지만, 글쓴이가 직접 심은 스크립트가 `link.coupang.com` 으로 보내는 경우는 **못 막는다**(위 열린 일 2번).
- **크롬 실제 앱**, **카카오톡 실제 앱**, **삼성 폰 실기기**: 시험 안 함.
- **GitHub 에서 스스로 업데이트**: 저장소가 없어 시험 못 함. (adb 로 덮어 설치했을 때 보호가 다시 켜지는 것은 확인)
- **상시 VPN(Always-on) 설정**과 **비공개 DNS 엄격 모드 경고**: 설정을 바꿔 보지 않음.
- 새로 생긴 사기 도메인은 목록에 오르기 전까지 통과한다.

## 알려진 한계

- 유튜브 앱 안 광고는 못 막는다(영상과 같은 서버). 유튜브 광고를 눌렀을 때 넘어가는 것(`googleadservices.com`, `doubleclick.net`)은 막는다.
- DNS 를 TCP 로 묻는 경우(아주 큰 답)는 처리하지 않고 버린다 → 그 질문만 실패. 일반 웹에서는 드물다.
- 크롬의 "보안 DNS"를 직접 특정 회사로 지정해 두면 그 브라우저는 우리 앱을 거치지 않는다(기본값 '자동'은 괜찮음).
- 남은 경고(lint): 배터리 최적화 제외 요청은 Play 스토어 정책 경고지만 이 앱은 스토어에 안 올리므로 해당 없음.
