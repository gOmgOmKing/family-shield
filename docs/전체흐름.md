# 전체 흐름

## 한 줄 요약

폰 안에 "가짜 VPN"을 하나 만들어, 앱들이 주소를 물어보는 질문(DNS)만 가로챈다.
광고·사기 주소면 "그런 주소 없음"이라고 답하고, 아니면 원래 인터넷의 DNS 서버에 그대로 물어서 답을 돌려준다.
나머지 인터넷 데이터는 VPN 을 지나가지 않는다 → 데이터 요금·속도 영향 없음, 방문 기록이 밖으로 나가지 않음.

## 패킷 하나가 지나가는 길

```
앱(크롬·카카오톡 인앱 브라우저 등) ─ DNS 질문 ─▶ 가짜 DNS 주소 10.111.222.2 / fd00:6a7e:5e1d::2
   ▶ VPN 통로(tun) ─▶ ShieldVpnService.readLoop
   ▶ DnsInterceptor.inspect  (IpPacket 로 UDP 꺼냄 → DnsMessage 로 이름 꺼냄 → DomainFilter 로 판정)
        ├ Block   : DnsMessage.nxdomain + IpPacket.buildUdpReply → 통로에 바로 답장, BlockLog 에 기록
        ├ Forward : DnsForwarder → 실제 망(UpstreamDns 가 아는 와이파이/모바일 DNS)에 그대로 질문 → 답을 통로로
        └ Ignore  : DNS 가 아닌 것은 버림
```

- 우리 앱 자신은 VPN 에서 뺐다(`addDisallowedApplication`). 그래서 목록 받기·업데이트·DNS 전달은 실제 망으로 바로 나간다.
- 차단된 사이트를 열면 브라우저에 "사이트에 연결할 수 없음"이 뜬다 → 뒤로 가기.

## 차단 규칙이 만들어지는 길

```
lists/ (저장소)  ──APK 에 같이 들어감──▶ 앱 assets (처음 설치 직후 기본 목록)
GitHub raw lists/*.txt ──6시간마다──┐
HaGeZi 3종 + List-KR ──하루 1번, 와이파이──┤▶ ListUpdater ▶ ListStore(폰 저장소, 마지막 정상본 유지)
                                     ▼
                         FilterBuilder.build ▶ DomainFilter (해시 정렬 배열, 약 45만 주소 ≈ 4MB)
```

- 같은 목록이 받은 사본과 앱 기본본 둘 다 있으면 받은 사본을 쓴다.
- 판정 순서: 허용 목록(allow) → 차단 목록(block + 커뮤니티 + 쿠팡 스위치가 켜졌으면 coupang). 상위 주소까지 본다(ad.daum.net 이 있으면 display.ad.daum.net 도 막힘). `com` 같은 최상위만으로는 막지 않는다.

## 밖으로 나가는 접속 (전부)

폰이 하는 접속은 모두 **받기만** 한다. 무엇을 보내지 않는다.

| 접속 대상 | 무엇 | 언제 | 예의 장치 |
|---|---|---|---|
| `raw.githubusercontent.com/<저장소>/main/lists/*.txt` | 직접 관리 목록 3개 + 자동 업데이트 스위치 | 6시간마다, 아무 망 | ETag, 요청 사이 2~3초, 403/429 하루 정지, 1MB 상한 |
| `raw.githubusercontent.com/hagezi/dns-blocklists/main/wildcard/{pro,popupads,tif.mini}-onlydomains.txt` | HaGeZi 목록 3개 (GPLv3) | 하루 1번, 와이파이만 | 같음, 16MB/8MB 상한, 최소 개수 검사 |
| `raw.githubusercontent.com/hagezi/dns-blocklists/main/wildcard/gambling-onlydomains.txt` | HaGeZi 도박 목록 (62만 개, 압축 전송 약 2.6MB) | 하루 1번, 와이파이만 | 같음, 32MB 상한, 최소 10만 개 |
| `cdn.jsdelivr.net/npm/@list-kr/filterslists@latest/dist/filterslist-DNS.txt` | List-KR DNS (한국 광고) | 하루 1번, 와이파이만 | 같음, 2MB 상한 |
| `raw.githubusercontent.com/<저장소>/collector-data/collector/block.txt` | 토토 후보 차단 파일 (스위치로 켠 분류만, 전부 끄기면 0개가 정상) | 하루 1번, 와이파이만 | 같음, 1MB 상한(봇이 2만 개에서 멈춤), 최소 0개 |
| `github.com/<저장소>/releases/latest/download/version.txt` → `family-shield.apk` | 새 버전 | 하루 1번, **스위치가 '켜기'일 때만** (꺼져 있으면 요청 없음) | 숫자가 클 때만 APK 받음, 30MB 상한 |
| 폰이 연결된 망의 DNS 서버 | 통과시킨 DNS 질문 | 앱들이 주소를 물을 때 | 질문을 그대로 전달만. 제3자 DNS 없음 |

User-Agent: `FamilyShield/<버전> (+https://github.com/<저장소>)`.

### GitHub Actions 가 하는 접속 (폰이 아님 — 토토 후보 관찰기)

| 접속 대상 | 무엇 | 언제 | 예의 장치 |
|---|---|---|---|
| `raw.githubusercontent.com/hagezi/nrd/main/domains/nrd7.txt` | HaGeZi 새 도메인 7일치 (약 267만 개, 압축 전송 약 15MB) | 하루 1번 | ETag, 압축, 요청 사이 3초, 403/429 하루 정지, 200MB 상한, 최소 10만 개, 재시도 없음 |
| `raw.githubusercontent.com/hagezi/dns-blocklists/main/wildcard/gambling-onlydomains.txt` | HaGeZi 도박 목록 (정확도 확인용) | 같음 | 같음 |

후보 도메인에는 접속하지 않는다(HTTP·DNS 없음). User-Agent: `FamilyShield-collector/1.0 (+https://github.com/gOmgOmKing/family-shield)`.

## 새 버전 내기 · 자동 업데이트 (오너가 직접, AI 없이)

- 순서는 루트의 **[새버전_설치방법.md](../새버전_설치방법.md)** 한 곳에만 적는다.
- 자동 업데이트는 **`lists/AUTO_UPDATE.txt` 스위치**로 켜고 끈다 (기본 꺼짐, 오너 결정 2026-10-31). 꺼져 있으면 폰은 업데이트 서버에 묻지도 않는다.
- 켜져 있을 때: 하루 1번 version.txt 확인 → 숫자가 크면 APK 받아 검증(패키지·버전·서명) → 설치 창. 앱이 떠 있으면 설치 창을 바로 열고, 아니면 알림 + 메인 화면 '새 버전 설치하기' 버튼.

## 목록 고치기 (오너가 직접, AI 없이)

GitHub 웹에서 `lists/allow.txt`(살릴 주소) 또는 `lists/block.txt`(막을 주소)를 열어 연필 아이콘 → 한 줄 추가 → Commit.
⚠ 폰은 GitHub 에서 받은 사본을 앱에 들어 있는 사본보다 우선한다. PC 의 `lists/` 를 고쳤으면 **GitHub 에 올려야** 폰에 반영된다.
부모님 폰은 6시간 안에 받는다(부모님이 '지금 새로고침'을 누르면 바로).
